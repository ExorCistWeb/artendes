ARTENDES ESTETIIKKA — ЧИСТАЯ ВЕРСТКА

Стек:
- HTML5
- CSS3
- Vanilla JavaScript

В проекте нет React, Next.js, Vue, jQuery, npm, сборщика и других зависимостей.

Запуск:
1. Откройте index.html в браузере.
2. Для разработки можно открыть папку любым локальным HTTP-сервером.

Структура:
- *.html — отдельные страницы сайта
- assets/css/style.css — все стили
- assets/js/main.js — меню, FAQ, модальное окно, формы, cookies и анимации
- assets/images — изображения

Важно:
- формы сейчас демонстрационные и не отправляют данные на сервер;
- контакты, цены и юридические тексты нужно заменить на финальные;
- для реального сайта подключите обработчик форм и сервис онлайн-записи.
